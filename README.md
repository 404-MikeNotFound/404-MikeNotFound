## Featured Projects

### 🔧 Power BI Schema Extraction Tools
A comprehensive toolset for extracting Power BI Desktop model schemas via XMLA endpoint.

**Features:**
- Connect to Power BI Desktop through XMLA endpoint
- Extract complete tabular model schema (tables, measures, relationships, DAX)
- Multiple script options: PowerShell, Python, and C# (Tabular Editor)
- Export to JSON, DAX, CSV, and human-readable reports
- Perfect for version control, documentation, and CI/CD pipelines

**Tools included:**
- `Extract-PBISchema.ps1` - Full-featured PowerShell extraction
- `extract_pbi_schema.py` - Python CLI with structured exports
- `ExtractSchema.csx` - Tabular Editor C# script
- Complete documentation and quick-start guide

📄 [View Documentation](./tabular-editor-skill.md) | [Quick Start Guide](./PBI-SCHEMA-EXTRACTION.md)
